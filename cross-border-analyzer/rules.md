# 用户前置规则（User Rules）

每次分析前，总控 skill 会先读取本文件，按这里的规则决定抓取范围、筛选条件、详情页补充和输出。
**改这里就能改行为**，不用动代码。

## 1. 分析范围

| 规则 | 值 |
|---|---|
| 平台 | FastMoss |
| 地区 | 美国 |
| 默认类目 | 时尚配件 |
| 默认榜单 | 新品榜 / 销量榜 |
| 时间范围 | 近 30 天（新品榜 = 上架日期近 30 天；销量榜 = 月榜） |

## 2. 商品筛选条件

| 规则 | 值 | 说明 |
|---|---|---|
| 最低价格 | 5 美元 | 低于此价过滤（平价饰品下限） |
| 最高价格 | 25 美元 | 高于此价过滤（平价饰品上限） |
| 佣金率下限 | 10% | 佣金低于此值过滤 |
| 周期销量下限 | 100 | 周期销量低于此值过滤（新品榜可选放宽） |
| 上架天数上限 | 60 天 | 只看较新的商品 |

## 3. 详情页补充（成交渠道占比）

| 规则 | 值 |
|---|---|
| 补充范围 | 每个榜单综合潜力 Top 20 |
| 补充字段 | 商品卡占比、店铺自营号占比、达人带货占比、带货达人数 |
| 达人依赖型阈值 | 达人带货占比 ≥ 60% |
| 自然流量型阈值 | 商品卡占比 ≥ 60% |

## 4. 评分权重（覆盖 scoring.md 的默认权重，可留空用默认）

| 维度 | 权重 |
|---|---|
| 销量与增长 | 30% |
| 价格带适配 | 20% |
| 佣金率 | 15% |
| 竞争度 | 15% |
| 生命周期 | 10% |
| 店铺质量 | 10% |

## 5. 输出偏好

| 产物 | 是否生成 |
|---|---|
| Markdown 报告 | 是 |
| 交互式仪表盘 | 是 |
| 评分排名 CSV | 是 |
| 报告语言 | 中文 |

## 6. 抓取参数

| 参数 | 值 |
|---|---|
| 榜单页数上限 | 50 页 |
| 翻页等待 | 3.5 秒 |
| 导航等待 | 5 秒 |
