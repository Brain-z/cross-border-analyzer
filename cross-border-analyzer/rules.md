# 用户前置规则（User Rules）

每次分析前，总控 skill 会先读取本文件，按这里的规则决定抓取范围、筛选条件、详情页补充和输出。
**改这里就能改默认行为**，不用动代码。

> **重要：本文件所有值都是默认值 / 示例，不是写死。** 每次分析以你本次说的为准——
> 国家、品类、榜单、时间、数量都可以在需求里临时指定；只有你没说的参数才用这里的默认值。
> 例如"换成英国看美妆个护的达人榜"就是一次合法需求，不需要先改本文件。

## 1. 分析范围

| 规则 | 值 |
|---|---|
| 平台 | FastMoss |
| 地区（默认） | 美国（可换：印尼 / 英国 / 越南 / 泰国 / 马来西亚 / 菲律宾 / 西班牙 / 墨西哥 / 德国 / 法国 / 意大利 / 巴西 / 日本 / 新加坡 / 沙特 / 奥地利 / 比利时 / 荷兰 / 波兰 / 葡萄牙等，以页面实际提供为准） |
| 类目（默认） | 时尚配件（可换任意 FastMoss 类目：美妆个护 / 女装与女士内衣 / 保健 / 箱包 / 运动与户外 / 手机与数码 / 居家日用……及子类） |
| 榜单（默认） | 商品榜（可换：达人 / 店铺 / 广告 / 素材 / 直播 / 品类大盘，含各子榜单） |
| 时间范围（默认） | 近 30 天（新品榜 = 上架日期近 30 天；销量榜 = 月榜；也可指定日榜 / 周榜 / 自定义日期） |

## 2. 商品筛选条件

以下过滤条件按当前需求生效；不适用时可临时调整或留空（不过滤）。

| 规则 | 值 | 说明 |
|---|---|---|
| 最低价格 | 5 美元 | 低于此价过滤（默认值，可改） |
| 最高价格 | 25 美元 | 高于此价过滤（默认值，可改） |
| 佣金率下限 | 10% | 佣金低于此值过滤（默认值，可改） |
| 周期销量下限 | 100 | 周期销量低于此值过滤（默认值，可改） |
| 上架天数上限 | 60 天 | 只看较新的商品（默认值，可改） |

## 3. 详情页补充（成交渠道占比）

| 规则 | 值 |
|---|---|
| 补充范围 | 每个榜单综合潜力 Top 20 |
| 补充字段 | 商品卡占比、店铺自营号占比、达人带货占比、带货达人数 |
| 达人依赖型阈值 | 达人带货占比 ≥ 60% |
| 自然流量型阈值 | 商品卡占比 ≥ 60% |

## 4. 评分权重（覆盖 scoring.md 的默认权重，可留空用默认）

| 维度 | 权重 |
|---|---|
| 销量与增长 | 30% |
| 价格带适配 | 20% |
| 佣金率 | 15% |
| 竞争度 | 15% |
| 生命周期 | 10% |
| 店铺质量 | 10% |

## 5. 输出偏好

按需生成，可临时指定（如"只要仪表盘"）。

| 产物 | 是否生成 |
|---|---|
| Markdown 报告 | 是 |
| 交互式仪表盘 | 是 |
| 评分排名 CSV | 是 |
| 报告语言 | 中文 |

## 6. 抓取参数

页面行数、翻页等待等可按需调整；页数上限决定最多抓多少条（约 10 条/页）。

| 参数 | 值 |
|---|---|
| 榜单页数上限 | 50 页 |
| 翻页等待 | 3.5 秒 |
| 导航等待 | 5 秒 |
