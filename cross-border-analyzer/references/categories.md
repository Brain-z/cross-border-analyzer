# FastMoss 品类映射表（种子表，非写死）

用途：把用户说的品类词翻译成 FastMoss 可用的类目，用于**抓取前的筛选参数**。
本表只是种子：**分析时的品类以实际抓到的数据范围为准**——先枚举数据里真实出现的类目，
再按它们分组、评分、做仪表盘筛选，不依赖这张表。

## 使用规则

1. 抓取前：先精确匹配"用户说法"；匹配不到时按关键词模糊匹配；仍不行则用用户原词做站内搜索；
2. 抓取后：**列出数据中实际出现的品类**（category 列的去重值），分析、评分、仪表盘筛选一律用真实类目；
3. 若数据里没有品类列，按"未知"处理并提示用户；
4. 把新发现的真实类目回填到本表，作为下次抓取的种子；
5. "国家 + 品类"组合筛不出来时，分两次抓取（先国家后品类）再合并。

## 更新方法

抓取后把数据中出现的真实类目路径补充到"FastMoss 类目建议"列（或者替换掉不准确的种子），
一行一条，不要改表头。
