# 跨境商品数据分析插件（cross-border-analyzer）设计规格

日期：2026-08-21

## 1. 目标与背景

为美国 TikTok 时尚配件 / 平价饰品网店卖家打造一个 Codex 个人插件，用于跨境商品数据分析：

- 从 FastMoss 获取 TikTok Shop 榜单数据（商品 / 达人 / 店铺 / 广告 / 素材 / 直播 / 品类大盘）；
- 对商品做标准化评分（市场热度、可做性、综合潜力）；
- 输出三类产物：Markdown 报告、交互式 HTML 仪表盘、Excel 评分排名表。

用户通过自然语言描述需求，例如"美国 时尚配饰 近 7 天 商品销量榜 Top 100"，插件自动完成
意图解析 → 数据抓取 → 清洗 → 评分 → 输出。

## 2. 架构

采用"一个总控 skill + 平台抓取 skill"的插件形态：

```text
cross-border-analyzer/
├── .codex-plugin/plugin.json      插件清单
├── skills/
│   ├── cross-border-analysis/     总控 skill：意图解析、路由、评分、报告、仪表盘
│   └── fastmoss-fetch/            FastMoss 抓取 skill：bsk 优先 → 内嵌浏览器 → 手动导入
├── scripts/                       共享脚本（清洗、评分、报告、仪表盘）
├── references/                    FastMoss 字段、品类映射、评分模型
└── assets/sample/                 示例数据（演示与测试）
```

首批只支持 FastMoss 一个数据源；后续平台（EchoTik、Kalodata 等）以新增抓取 skill 的方式扩展，
不改动总控 skill 的核心逻辑。

## 3. 数据获取

### 3.1 认证方式

- 不需要 FastMoss API key（企业版 API 价格高，默认不采用）；
- 需要用户有一个已登录 FastMoss 的浏览器会话（专业版账号，数据覆盖完整）；
- bsk（BrowserSkill）为可选的第三方浏览器桥接工具，未安装时自动降级。

### 3.2 抓取降级顺序

1. bsk CLI 可用 → 命令行驱动用户已登录的 Chrome/Edge 抓取；
2. bsk 不可用 → 使用 Codex 内嵌浏览器导航到榜单页翻页抓取；
3. 均失败 → 提示用户从 FastMoss 网页导出 CSV 到 `data/import/`，继续分析。

### 3.3 榜单模块与筛选维度

| 模块 | 子榜单 | 筛选维度 |
|---|---|---|
| products 商品榜 | 新品 / 销量 / 热推 | 国家、品类、店铺类型 |
| creators 达人榜 | 涨粉 / 带货 / 蓝V / 热门 / 黑马 | 国家、时间 |
| shops 店铺榜 | 销量 / 热推 | 国家 |
| ads 广告趋势 | 标签 / 关键词 / 品类 | 国家、时间 |
| creatives 素材榜 | 视频 / 音乐 / 标签 | 国家、时间 |
| livestreams 直播榜 | TT直播 / 直播爆品 / 直播达人 | 国家、时间 |
| market 品类大盘 | 行业格局 / 市场总览 / 日销趋势 | 国家、时间 |

参数转换规则：

- 地区：中文名与 ISO 代码互认（美国 ↔ US）；
- 时间："近 7 天" → 日榜；"周榜 / 月榜" → 对应榜单；
- 数量："Top 100" → 按每页约 20 条折算页数；
- 品类：先查 `references/categories.md` 映射表，匹配不到走模糊搜索；
- 国家 + 品类组合：社区脚本一次只支持一种筛选，本插件做两次抓取后合并。

## 4. 意图解析

总控 skill 第一步把自然语言需求翻译成结构化参数：

```text
{ 平台: FastMoss, 模块: products, 榜单: 销量榜, 地区: US, 品类: 珠宝及饰品,
  时间: 日榜, 数量: 100 }
```

支持模糊表述，缺省值默认：平台=FastMoss、时间=周榜、地区=美国、品类=饰品、数量=50。

## 5. 评分模型

评分权重保存在 `references/scoring.md`，默认针对美国时尚配饰 / 平价饰品调校：

| 维度 | 默认权重 | 说明 |
|---|---|---|
| 销量与增长 | 30% | 周期销量 + 日销趋势 |
| 价格带适配 | 20% | 5–25 美元平价区间加分 |
| 佣金率 | 15% | 越高越值得做 |
| 竞争度 | 15% | 同品类在榜数量、新品占比 |
| 生命周期 | 10% | 上架天数短且仍在增长 |
| 店铺质量 | 10% | 店铺评分、在榜商品数 |

每个商品输出三个分数：市场热度分、可做性分、综合潜力分；排名表带异常标记
（暴涨新星 / 价格战红海 / 高佣爆款）。

## 6. 输出

统一写入 `output/`：

1. `report.md`：需求复述 → 市场概览 → Top 榜单 → 选品建议 → 风险提示；
2. `dashboard.html`：交互图表（价格分布、销量趋势、评分散点）+ 筛选器（价格区间、销量下限），
   纯 HTML/CSS/JS 实现，无外部依赖；
3. `output.xlsx` 或 CSV：原始数据 + 评分排名，Excel 可直接打开（UTF-8 BOM）。

## 7. 目录与运行约定

- `data/`：原始抓取数据（CSV，UTF-8 BOM），原始字段不做改动；
- `data/import/`：手动导出文件的放置目录；
- `output/`：每次分析生成的产物；
- 脚本使用 Python 标准库为主（csv / json / statistics），避免第三方依赖；
- 每轮分析生成带时间戳的子目录，避免覆盖历史结果。

## 8. 首批范围（YAGNI）

- 只做 FastMoss 数据源；只做商品榜（新品 / 销量 / 热推）+ 品类大盘为 v1 核心，
  达人 / 店铺 / 广告 / 素材 / 直播榜单通过同一抓取框架覆盖；
- 不做 FastMoss 官方 API 集成；
- 不做自有运营数据自动抓取（保留手动导入识别能力）。

## 9. 后续扩展

- 新增平台：加一个 `skills/<platform>-fetch/` + 对应 references，注册进总控 skill 的路由表；
- 调整评分：改 `references/scoring.md` 权重；
- 增加输出：Word/PDF 报告（复用 documents / pdf 技能）。
